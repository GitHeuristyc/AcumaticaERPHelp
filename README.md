# Acumatica Documentation Repository

This repository contains the complete Acumatica documentation in Markdown format, extracted from the official Acumatica documentation website. The goal is to make this documentation freely available to everyone and easily indexable for AI tools like Cursor.

## 📚 Available Documentation

This repository includes comprehensive guides covering all aspects of Acumatica development and customization:

### Core Development Guides
- **[Framework Development Guide](FrameworkDevelopmentGuide.md)** - Complete guide to the Acumatica Framework, including data access, business logic, UI development, and application architecture
- **[Customization Guide](CustomizationGuide.md)** - Comprehensive guide to customizing Acumatica applications, including project management and deployment
- **[Integration Development Guide](IntegrationDevelopmentGuide.md)** - Guide for developing integrations with external systems and APIs
- **[Mobile Framework Guide](MobileFrameworkGuide.md)** - Documentation for developing mobile applications with Acumatica

### UI and Component Guides
- **[UI Development Guide](UIDevelopmentGuide.md)** - Guide for developing user interfaces in Acumatica
- **[UI Component Reference Guide](UIComponentReferenceGuide.md)** - Complete reference for all UI components and their properties

### Data and Architecture Guides
- **[DAC Overview Guide](DACOverviewGuide.md)** - Data Access Class (DAC) documentation and best practices
- **[Plugin Development Guide](PlugingDevelopmentGuide.md)** - Guide for developing plugins and extensions

### Testing and Workflow
- **[Unit Test Framework Guide](UnitTestFrameworkGuide.md)** - Comprehensive guide to testing Acumatica applications
- **[Workflow API Guide](WorkflowAPIGuide.md)** - Documentation for workflow development and automation

### Specialized Guides
- **[Barcode Driven Guide](BardcodeDrivenGuide.md)** - Guide for barcode-driven processes and implementations

## 🎯 Purpose

This repository serves several important purposes:

1. **Free Access**: Makes Acumatica documentation freely available to the entire developer community
2. **AI Tool Compatibility**: Markdown format allows easy indexing and searching by AI tools like Cursor, GitHub Copilot, and other development assistants
3. **Version Control**: Enables tracking of documentation changes and contributions
4. **Offline Access**: Developers can download and access documentation without internet connectivity
5. **Community Collaboration**: Enables the community to suggest improvements and corrections

## 📖 How to Use

### For Developers
- Browse the guides based on your development needs
